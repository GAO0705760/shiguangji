🍱 食光机 —— 让每一份食材都被温柔以待
智能食材效期管理引擎 · 空天信息学院竞赛项目（赛题一）
把冰箱里的效期管理，做成可切换「家用数据包 / 空间站数据包」的一套参数化引擎。
一句话定位
食光机是一个食材效期管理工具：扫码/录入食材 → 自动计算剩余效期 → 临期提醒与优先食用建议。内核采用多因子参数化设计，同一套引擎可通过切换数据包适配家用冰箱与空间站食品系统。
为什么做这个
- 家用场景：冰箱食材过期浪费严重，缺乏直观的「先吃什么」决策支持
- 空天场景：空间站食品保质期分级复杂（复水/热稳定等工艺路线），效期计算逻辑与家用完全不同
- 我们的答案：效期引擎的多因子参数化——换数据包不换内核
功能特性
[ ] 食材录入与效期自动计算（剩余天数 / 临期分级）
[ ] 多因子效期模型：温度、包装工艺、开封状态等参数可配置
[ ] 数据包切换：家用数据包 ↔ 空间站食品数据包（基于 NASA 公开 ISS 食品清单，101 项）
[ ] 临期清单置顶 + 一键处理建议
